# Changelog

## 1.0.0 — 2026-11-18

- First public release.
- Tested battery reporting for Logitech G305 SE through LIGHTSPEED receiver `046D:C53F`.
- Standard Windows battery-property fallback for compatible Bluetooth mice.
- Percentage tray icon with green, amber, red, and unavailable states.
- Manual refresh, optional Windows startup, and clean exit commands.
- Five-minute polling interval and single-instance protection.
