# Changelog

## 1.1.3 — 2026-11-18

- Spaced the refresh arrowhead away from the circular stroke.

## 1.1.2 — 2026-11-18

- Redrew the refresh symbol and removed seams from the startup switch at different display scales.

## 1.1.1 — 2026-11-18

- English panel labels, smoother controls and refresh icon, and a clean dark panel edge.

## 1.1.0 — 2026-11-18

- Dark tray panel with a battery summary, refresh button, and Windows startup switch.
- Rounded gradient tray icon with larger digits.

## 1.0.0 — 2026-11-18

- First public release.
- Tested battery reporting for Logitech G305 SE through LIGHTSPEED receiver `046D:C53F`.
- Standard Windows battery-property fallback for compatible Bluetooth mice.
- Percentage tray icon with green, amber, red, and unavailable states.
- Manual refresh, optional Windows startup, and clean exit commands.
- Five-minute polling interval and single-instance protection.
